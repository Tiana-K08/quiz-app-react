# Quiz App

**Quiz App** - це багатокрокова вікторина, створена на React 18, яка інтегрується з Contentful CMS для динамічного завантаження питань.  
Проєкт оптимізований для адаптивного відображення на мобільних пристроях і демонструє повний стек сучасного фронтенду для портфоліо.

---

## Онлайн-версія

Переглянути проєкт можна тут: https://quiz-app-react-gamma-one.vercel.app/

---

## Мета проєкту

- Створити багатокрокову вікторину з динамічними питаннями.
- Навчитися інтеграції зовнішніх сервісів (CMS).
- Реалізувати сучасний стек: React 18 + Vite + Redux Toolkit + SCSS + CSS Modules.
- Підготувати проект до деплою.

---

## Функціональні можливості

1. **Динамічні кроки вікторини**

   - Кожен крок може містити одне або декілька питань.
   - Підтримуються різні типи питань:
     - Multiple choice (чекбокси)
     - Open-ended (текстове поле)
   - Прогрес користувача відображається через прогрес-бар та нумерацію кроків.

2. **Глобальний стан вікторини**

   - Використано Redux Toolkit для збереження відповідей користувача.
   - Прогрес і відповіді зберігаються при переході між кроками.

3. **Інтеграція з Contentful**

   - Динамічне завантаження кроків та питань через Contentful API.
   - Можливість налаштовувати кількість кроків та типи питань у CMS.

4. **Адаптивний дизайн**

   - Працює на мобільних, планшетах і десктопах.
   - Кнопки, прогрес-бар і поля вводу адаптуються до розміру екрану.

## Запуск проєкту локально

1. Клонувати репозиторій:

```bash
git clone <repository-url>
cd quiz-app
```

2. Встановити залежності:

```bash
npm install
```

3. Запустити локально:

```bash
npm run dev
```

Відкрити в браузері http://localhost:5173
